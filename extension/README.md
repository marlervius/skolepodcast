# Lytterom for NotebookLM (Chrome-utvidelse)

Send podkaster (Audio Overviews), videoer (Video Overviews) og nøkkelpunkter direkte fra `notebooklm.google.com` til fagrommene dine i **Lytterom** — uten å mellomlagre filer manuelt.

## Slik installerer du utvidelsen lokalt (Chrome / Edge / Arc / Brave)

1. Åpne `chrome://extensions` i nettleseren.
2. Slå på **Utviklermodus** (øverst til høyre).
3. Klikk **Last inn upakket** (*Load unpacked*) og velg denne `extension`-mappen.
4. Fest **Lytterom for NotebookLM** i verktøylinjen hvis du vil ha rask tilgang.

## Koble til lærerkontoen din

1. Logg inn i **Lærerstudio** (`/studio`) og klikk på **NotebookLM** → fanen **Chrome-utvidelse**.
2. Klikk **Lag og kopier nøkkel**.
3. Klikk på Lytterom-ikonet i Chrome, sjekk at serveradressen stemmer (standard er `https://skolepodcast.vercel.app`, eller `http://localhost:3000` lokalt), og lim inn nøkkelen. (Du kan også logge inn med e-post og passord direkte i utvidelsen.)

## Slik bruker du den i NotebookLM

1. Åpne en notatbok på <https://notebooklm.google.com>.
2. Trykk **Spill av** på lyd- eller videooversikten du vil publisere (utvidelsen fanger opp mediekilden automatisk), eller last ned filen og dra den inn i panelet.
3. Klikk på **«Send til Lytterom»** nederst til høyre på skjermen.
4. Velg **Fagrom** og **Kapittel** (eller opprett et nytt kapittel rett i panelet), sjekk tittelen, hent eventuelt markert tekst som nøkkelpunkter, og trykk **Publiser til Lytterom**.
5. Store `.wav`-filer fra NotebookLM komprimeres automatisk til `.m4a` i nettleseren før opplasting.
